This project implements a Video Streaming System based on the RTSP/RTP Architecture, with a graphical client developed in Python using Tkinter. 
The client receives RTP packets, decodes them, extracts the video frames, and displays them in real time through a simple GUI. 
The system also includes an RTP packet handler for packet encoding and decoding, as well as a video stream reader that processes JPEG frames directly from the video file by detecting image start and end markers. 
Overall, the project demonstrates the practical implementation of multimedia streaming concepts, socket programming, packet-based communication, and real-time video delivery in a client-server environment.
